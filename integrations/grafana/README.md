# 📊 Grafana SOC Dashboard Integration

This directory contains the Grafana dashboard template for real-time visualization of alert volume, severity breakdown, MITRE ATT&CK coverage, and attacker IP reputation.

## 🚀 How to Import into Grafana
1. Open your Grafana instance (e.g. `http://localhost:3000`).
2. Go to **Dashboards** ➔ **New** ➔ **Import**.
3. Upload `soc_dashboard.json` or paste its JSON content.
4. Select your data source (SQLite, PostgreSQL, or OpenSearch/Elasticsearch).
5. Click **Import**!
